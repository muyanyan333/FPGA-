## 故障结论与待实机确认

用户反馈“音量小一点”无反应，但尚未确认“下一张”是否能执行、当前模块
是否含新版模型，因此不能断言唯一根因。当前源码和实际 .hd 均包含音量指令，
上述仿真未复现音量通路故障；FPGA RTL 无需为此猜测性修改。

新版 .hd 必须在天问 Block 生成模型并编译下载到 ASRPRO 才生效；仅替换
电脑文件、TF 卡内容或 FPGA bit 不会更新 ASRPRO 的识别词库。
本次没有执行模型云端生成、串口烧录或 FPGA 重编译，没有保证实机识别成功。

上板排查顺序：

1. 加载新版 .hd，确认唤醒方式为“永远”、UART0=9600，生成并下载模型。
2. 上电应听到新版“永久唤醒”提示，直接说“下一张”“音量五级”“静音”。
3. “你好”也没有响应：检查语音模块供电、麦克风和烧录结果。
4. 本地问答能响应但所有控制都失败：检查 ASRPRO TX/PB5 到 J1-3/G12、
   FPGA J1-4/F13 到 ASRPRO RX/PB6，确认共地及 3.3V 兼容数据电平。
5. 蓝牙调音量有效、语音调音量无效：优先检查 ASRPRO 模型与实际发送字节。
   “音量小一点”应发 A5 22 00 87；“音量五级”发 A5 20 05 80；
   静音发 A5 23 01 87，取消静音发 A5 23 00 86。
6. 蓝牙也无法调音量：核对下载的 FPGA 固件是否含音量功能，以及音频是否
   确实来自 FPGA HDMI；这些命令不控制 ASRPRO 自身喇叭播报音量。

当前视频参考固件见 `docs/VIDEO_PLAYBACK.md`，不要按旧 ASRPRO 文档尾部
的历史 full_build_asrpro_duplex.bit 回退，旧版本不含全部新音量功能。
