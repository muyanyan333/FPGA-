# 2026-10-20 控制逻辑优化

## 修改

- 模式确认以本次收到的 86 帧为准，修复用旧模式判断而产生的确认延迟 / 错误确认。
- 同一次接收中的多帧状态处理完成后统一刷新页面和连接状态，减少 Android WebView 的重复 DOM 更新。保留逐帧状态与日志，支持末尾残留半帧。
- Android BLE 写入增加等待回调标记及任务身份检查，忽略同一分包在节流等待期间重复到达的写入回调；权限或蓝牙状态变化造成的写入异常转换为断开提示。
- 手机语音识别使用会话编号，停止、切后台或重新开始后不执行旧识别结果；每次重新识别释放旧识别器。

网页两份入口同步更新，再由 `sync_controller.py` 同步到 Android 本地资源。UART 协议与 FPGA RTL 本次未改动，沿用原 bit。

## 验证

`test_adapter.cjs` 的新模式确认、非目标模式不确认、批量帧只刷新一次和尾部半帧恢复测试通过；现有 528 条语音词条、模式超时及断开重连测试通过。Android 2.0.1（versionCode 21）已重新编译成功，手机蓝牙及语音仍需实机验证。
