## 接线与串口配置

- ASRPRO **TX/PB5 → J1 第 3 脚 GPIOA2/G12**（FPGA `voice_rx`）。
- FPGA **J1 第 4 脚 GPIOA3/F13 → ASRPRO RX/PB6**（FPGA `voice_tx`）。
- ASRPRO **GND → J1 第 12 或 30 脚 GND**。VCC 是供电引脚；若 ASRPRO 已单独供电，不重复连接 VCC。若由开发板供电，先核对 ASRPRO 所需电压和电流，再使用相应电源脚。W02 仍用 J1 第 1/2 脚。
- 两侧数据引脚须为 **3.3 V 兼容电平**；5 V 数据输出须做电平转换。串口0设 **9600 baud、8N1**，发送模式为十六进制字节。

FPGA 接收的每条命令固定为 4 字节：`A5 CMD ARG CHECK`，其中 `CHECK = A5 XOR CMD XOR ARG`。不要把 `A5` 当作 ASCII 字符串发送，也不要附加换行。识别一次发送一帧。校验错误或参数越界的帧会被丢弃；下一帧的 `A5` 会使接收器重新对齐。W02 与 ASRPRO 各有独立 RX，两个模块可同时连接。

FPGA 收到有效 ASRPRO 命令后，将下一次状态上报的第一帧送到 `voice_tx`：`5A 81 COUNT CURRENT FLAGS MAP_L MAP_H CHECK`，`CHECK` 为前 7 字节异或。`COUNT` 为图片总数，`CURRENT` 为从 1 开始的当前图片序号，`FLAGS` 低位表示自动模式和扫描完成。ASRPRO 工程用串口0的 `5A 81` 前缀识别回包，并播报“FPGA已收到指令”；语音识别本身不再提前播报成功。连续状态流不会周期性灌入 ASRPRO RX，只在语音命令后回传一帧。完整图片/音乐状态仍发给 W02。

## 扩展语音词库

`语音控制/语音控制.hd` 由 `语音控制/build_asrpro_project.py` 生成，现有 **528 条不重复识别短句**，其中 472 条发送 FPGA 命令、56 条在 ASRPRO 本地播报。2026-10-22 起唤醒词改为“你好”，并启用 **永久唤醒（mode=2）**：上电后直接识别指令，不会自动休眠，无需每次先说唤醒词。配置中的 second=1000 仅保留为有效 UI 字段，不作为永久模式的退出时间。可直接说“语音控制帮助”或“你会做什么”。完整短句及对应帧见 `语音控制/词条清单.md`。

- 图片切换支持“下一张”“换一张图片”“切到下一张”等常用说法，以及“显示第 X 张”“切换到第 X 张图片”（1–16）。
- 每档亮度和对比度都可直接指定，例如“亮度调到五档”“对比度调到七档”；也可说“图片亮一点”“对比度低一点”。
- 尺寸、比例、转场、歌词和歌名都有设置、切换或开关短句。
- 音乐支持上一首、下一首、播放、暂停、七首歌名以及“播放第 X 首”（1–7）；如“我想听心似烟火”。
- 本地互动还支持“讲个笑话”“夸夸我”“来句诗”“晚安”等，不需要 FPGA 回包；W02 网页版也识别相同短句。
- 摄像头支持“打开摄像头”“开启摄像头”“查看实时画面”“实时预览”；返回时说“关闭摄像头”“返回图片音乐”或“返回相册”。对应 `1D 01` 和 `1D 00`。
- 新增“再看一张”“先停在这张”“我想安静一下”“接着放音乐”等自然说法，以及诗词、绕口令、谜语、问候和退出时间说明。

更改歌曲列表或词库后运行 `python 语音控制/build_asrpro_project.py` 重新生成工程。该脚本会检查短句重复、词条数量和串口帧校验，并同步两份 W02 网页的精确短句表及显示数量。运行 `python 语音控制/validate_voice_catalog.py` 检查实际 .hd 的永久模式、唤醒词、UART0 9600、全部短句/串口帧，以及两份网页原句和唤醒前缀的解析结果。

本轮新增 22 条频谱控制及帮助词条；此前新增 150 条图片编号、逐档亮度/对比度、点歌、摄像头控制及趣味问答。472 条为工程配置数量，尚未执行天问Block模型编译，实际模型容量需生成时确认。频谱协议及使用方法见 `SPECTRUM_VOICE_CONTROL.md`。

永久唤醒属于 ASRPRO 配置，不改变 FPGA 图片属性编辑的按键行为。更新 `.hd` 后须在天问Block重新生成并下载语音模型，设备才会使用新词库和永久模式。此处仅生成工程，没有执行云端模型生成或烧录。

### 网页语音与模式确认优化

W02 网页支持在原短句前说“小美”，以及“请”“帮我”等常见前缀和“好吗”等结尾；原词库短句优先精确匹配，保留本地问答。包含“不要”“别”“不用”等否定词的非词库句子不发送设备命令。开始识别前取消网页播报，减少扬声器回声。

合并版网页的摄像头/相册模式切换只接受与目标模式相符的状态回包；4 秒未确认时解除等待并提示重试。异步发送通过请求编号和连接编号隔离，避免旧请求失败或旧连接返回覆盖新操作。上述解析、否定句、超时和并发场景已加入 `validate_voice_catalog.py` 检查。

## 适合直接录入 ASRPRO 的短句

| 语音短句示例 | 发送的十六进制字节 | 动作 |
|---|---|---|
| 查询设备状态 | `A5 01 00 A4` | 请求 FPGA 回传图片状态并播报接收确认 |
| 下一张 | `A5 04 00 A1` | 下一张图片 |
| 上一张 | `A5 05 00 A0` | 上一张图片 |
| 自动播放图片 | `A5 03 00 A6` | 图片自动轮播 |
| 手动播放图片 | `A5 06 00 A3` | 图片手动模式 |
| 切换转场 | `A5 13 00 B6` | 直接切换→淡入淡出→滑动→循环 |
| 调亮一点 | `A5 14 00 B1` | 亮度加一，最高 9 |
| 调暗一点 | `A5 15 00 B0` | 亮度减一，最低 0 |
| 增加对比度 | `A5 16 00 B3` | 对比度加一，最高 9 |
| 减少对比度 | `A5 17 00 B2` | 对比度减一，最低 0 |
| 切换图片大小 | `A5 18 00 BD` | 640×480→512×384→320×240→循环 |
| 切换图片比例 | `A5 19 00 BC` | 原比例→4:3→16:9→1:1→循环 |
| 上一首 | `A5 11 00 B4` | 切换上一首可用歌曲 |
| 下一首 | `A5 12 00 B7` | 切换下一首可用歌曲 |
| 暂停音乐 | `A5 0E 00 AB` | 暂停 |
| 播放音乐 | `A5 0E 01 AA` | 播放 |
| 播放或暂停 | `A5 1C 00 B9` | 切换播放状态 |
| 切换歌词 | `A5 1A 00 BF` | 开关歌词 |
| 切换歌名 | `A5 1B 00 BE` | 开关歌名 |

“下一张”和“上一张”会进入手动图片模式。大小和比例是**按当前图片分别保存**的。

## 指定图片和歌曲

指定图片使用 `CMD=02`，指定歌曲使用 `CMD=0D`；`ARG` 是十六进制序号 `01`～`10`（对应 1～16）。例如“显示第三张”发送 `A5 02 03 A4`。图片不存在、歌曲没有对应 WAV 时不会切换。

| 语音短句示例 | 发送的十六进制字节 |
|---|---|
| 播放童话镇（01） | `A5 0D 01 A9` |
| 播放爱的回归线（02） | `A5 0D 02 AA` |
| 播放红色高跟鞋（03） | `A5 0D 03 AB` |
| 播放喜欢你（04） | `A5 0D 04 AC` |
| 播放静悄悄（05） | `A5 0D 05 AD` |
| 播放那时雨（06） | `A5 0D 06 AE` |
| 播放心似烟火（07） | `A5 0D 07 AF` |

W02 原有的设置命令也能由 ASRPRO 发送：`07` 设置转场（参数 0～2），`08` 设置亮度（0～9），`09` 设置对比度（0～9），`0B` 设置图片大小（0～2），`0C` 设置图片比例（0～3），`0F` 设置歌词显示（0/1），`10` 设置歌名显示（0/1）。完整参数见 [UART_BLUETOOTH_PROTOCOL.md](UART_BLUETOOTH_PROTOCOL.md)。

FPGA 须使用包含语音串口及音量功能的当前固件，视频版选择见 `../docs/VIDEO_PLAYBACK.md`；不要回退到不含新音量功能的历史 `full_build_asrpro_duplex.bit`。`voice_rx` 和 `voice_tx` 管脚均约束在 `src/user_source/constraints_source/pin.adc`。本次语音排查、验证及烧录检查见 `../docs/VOICE_CHECK_20261022.md`。
