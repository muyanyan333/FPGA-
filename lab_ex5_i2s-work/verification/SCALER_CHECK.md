# 图片缩放上板验证

测试图在 `scaler_bmps/`，均为 24 位无压缩 Windows BMP，像素偏移 54 字节。把 `.bmp` 文件复制到 exFAT TF 卡根目录；建议使用备用卡，使它们位于根目录前 16 个普通文件之内。可同时复制 `06_silence_48k_16bit.wav`，降低音乐可视化对图片检查的遮挡。无需运行旧版 `sync_to_sd.py`。

1. 用 HDMI_B 连接显示器，下载 `../src/td_project/full_build_probe.bit`。
2. 上电后短按 KEY4 进入手动播放，再用 KEY3 逐张切换。注意按文件系统扫描顺序识别，数码管序号可辅助确认。
3. 按下表检查图片边框、圆形和黑边；屏幕中部和底部会有音乐可视化叠加。

| 测试图 | 预期结果 |
|---|---|
| `01_native_640x480.bmp` | 直接铺满 640×480；四角颜色块可见，圆形不变形。 |
| `02_upscale_320x240.bmp` | 放大 2 倍铺满，无黑边；细线比原尺寸更粗。 |
| `03_wide_1280x720.bmp` | 等比例缩为 640×360；上下各约 60 像素黑边。左上细密黑白竖条应趋于灰色。 |
| `04_portrait_480x800.bmp` | 等比例缩为 288×480；左右各约 176 像素黑边，圆形不变成椭圆。 |
| `05_padding_321x240.bmp` | 图片内容完整且颜色不串行，用于发现 BMP 每行填充字节处理问题。 |

判定重点：每张图片都能找到；四角颜色块顺序正确；格线不倾斜或逐行错位；宽屏和竖图比例正确。若切换后黑屏或花屏，先确认卡为 exFAT、文件位于根目录前 16 项且 TF 卡接触可靠。

当前完整布线虽已生成 bit，时序报告仍有 SWNS -6.699 ns；单次上板成功不代表长期稳定。建议每张图至少观察数分钟，并反复切换、断电重启。若复现问题，保留测试图名称、现象照片和数码管序号以便定位。
