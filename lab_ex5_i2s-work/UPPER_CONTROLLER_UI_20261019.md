# W02 上位机页面优化

- 桌面采用侧栏导航，手机保留七项底部导航；卡片布局、焦点样式和减少动画偏好统一。
- 总览新增前后切图、前后切歌快捷操作；连接栏显示回传活跃状态。超过 5 秒无新帧时标记为最后已知状态，提供刷新按钮。
- 新增语音指令库子页面，支持全部 300 条指令的分类、关键词/回复内容搜索、分批展示。点击短句只填入语音页，随后由用户执行。
- 歌单按钮显示编号和歌名；手机音乐主控制固定三列。
- 摄像头模式下禁用当前固件暂不处理的图片音乐控件，显示返回入口；切回后恢复控件。相同限制用于网页语音命令。
- 命令发送与失败提供临时提示，仍由设备回传决定实际状态。

主文件 `bluetooth_image_controller.html` 已完整同步至同级另一目录 `lab_ex5_i2s/bluetooth_image_controller.html`。网页解析、模式确认、并发、超时及语音退出字段验证均通过。浏览器演示验证了搜索填入、快捷切图/切歌、摄像头/播放器联动和歌词开关；390px 手机与默认桌面视口无横向溢出，无重复 ID，无浏览器控制台错误。未连接真实蓝牙硬件测试此次页面改动。
