# W02 影音控制台 Android 2.0.1

安装包：`W02_Controller_Android.apk`。包名沿用 `com.wangzedong.fpgaimagecontroller`，versionCode 21，与旧 BLE APK 使用同一调试签名，可覆盖安装。

## 使用

1. 将 APK 发送到安卓手机并安装，打开“W02 影音控制台”。
2. 点击“扫描BLE”，按系统提示允许附近设备权限，选择 W02。Android 6～11 还需位置权限和位置服务。
3. 数据通知开启后自动查询 FPGA。显示“有回传”才表示已收到 FPGA 数据；单纯蓝牙连接不会被当作设备已执行命令。
4. 语音页可使用手机语音识别或输入文字。首次聆听需要麦克风权限；手机需安装中文语音识别服务，是否可离线由手机服务决定。ASRPRO 独立模块的语音功能继续保留。

页面：总览、图片、音乐、摄像头切换、语音、通知、设置；语音页可打开完整的 528 条词库。包含八首歌曲、图片尺寸/比例/亮度/对比度/转场、歌词/歌名/底部频谱开关、音量及静音。摄像头页切换 FPGA 的 HDMI 输出，不在手机上传输摄像头视频。

音量控制需下载 `src/td_project/camera_player_volume_manual.bit` 或同内容默认 `camera_player.bit`。手动模式不定时换图，只有自动模式轮播。旧固件未报告相应能力时控件保持禁用。

## 实现与维护

- 安卓工程位于 `../lab_ex5_i2s/android_app`，启动入口为 `ControllerActivity.java`。界面为随 APK 打包的本地 WebView，BLE、设备扫描、权限、语音识别及播报由 Android 原生接口提供，无需浏览器或网页服务器。
- 优先读取设置页 UUID，兼容 W02 FFE0/FFE1 和 Nordic UART 服务。只在 CCCD 通知启用成功后标记连接可用。
- 原生 GATT 串行队列、20 字节分包、每包留 40 ms 给 9600 baud 透传、5 秒写超时及连接身份检查；断开拒绝全部未完成写入。
- 原有帧解析接收 81～87 状态帧，支持粘包/分包、校验失败后重同步。命令仍为 `A5 CMD ARG XOR`。
- WebView 禁止网络加载、外部页面导航、文件跨域和通用文件访问。回传文本用 JSON 转义。
- 修改上位机后运行安卓工程下的 `sync_controller.py` 更新 APK 资源，再运行 `build_apk.ps1` 构建。`test_adapter.cjs` 验证资源脚本及安卓适配层。
